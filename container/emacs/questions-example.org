#+TITLE: Questions from the manager
# One heading with an :ID: per question. C-c C-c ticks a box, C-c C-SPC opens
# the menu. Saving marks answered questions STAGED and folds them; C-c C-SPC s sends
# the answered ones (DONE) and, once nothing is left open, closes the buffer.

#+begin_note
A note above the first heading goes with every submit (buffer notes).
#+end_note
